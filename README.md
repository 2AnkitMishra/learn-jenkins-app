# 🎮 Catch the Bug – React Game

A fun and interactive mini-game built with React where users catch moving bugs to score points before time runs out.

---

## 🚀 Live Demo

👉 https://your-netlify-link.netlify.app

---

## 🧠 Features

* 🎮 Interactive gameplay
* ⏱ Real-time countdown timer
* 🐛 Dynamic moving elements
* 📈 Score tracking
* 🔁 Restart functionality
* ⚛️ Built with modern React (Hooks)

---

## 🛠 Tech Stack

* React
* JavaScript (ES6+)
* CSS3
* Playwright (E2E Testing)
* Jest + React Testing Library

---

## 🧪 Testing

### Run Unit Tests

```bash
npm test
```

### Run E2E Tests

```bash
npx playwright test
```

## 📦 Build
